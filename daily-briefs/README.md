# Daily Briefs

This directory stores sample or user-generated daily brief files.

这个目录保存每日早报文件，可以是示例，也可以是用户自己的每日整理结果。

Default flow / 默认流程：

1. Generate a short `YYYY-MM-DD.md` brief.
2. Put optional Todo candidates under `可加入 Todo 候选`.
3. Edit candidate wording if needed.
4. Add selected candidates to `todo.md`.
