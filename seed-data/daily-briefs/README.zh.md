# 每日早报

每日早报保存在这里，文件名使用 `YYYY-MM-DD.md`。

## 固定结构

FocusDock 能读取中文和英文分区标题。新的中文早报应使用：

- `## 今天`
- `## 临近截止`
- `## 需要确认`
- `## 可选活动`
- `## 垃圾/忽略`
- `## 可加入 Todo 候选`

普通分区必须使用编号列表。Todo 候选必须编号，并且每条短 Todo 必须用反引号包起来。

## 最小模板

```markdown
# YYYY-MM-DD 每日早报

## 今天

1. 项目：用一句话说明时间、地点、相关性和现在需要做的事。

## 临近截止

1. 项目：截止时间或临近安排，以及是否需要行动。

## 需要确认

1. 项目：需要用户确认的信息或选择。

## 可选活动

1. 项目：可选但有价值的近期活动。

## 垃圾/忽略

1. 项目：普通推广、简报或无需行动的信息。

## 可加入 Todo 候选

1. `项目：行动/关键词 @YYYY-MM-DD`
2. `项目：无日期行动`
```

每日早报承载背景信息。Todo 只提醒用户行动项。
