# Daily Briefs

Daily briefs are stored here. File names use `YYYY-MM-DD.md`.

## Fixed Structure

FocusDock can read English and Chinese section headings. New English briefs should use:

- `## Today`
- `## Approaching Deadlines`
- `## Needs Confirmation`
- `## Optional Events`
- `## Trash / Ignore`
- `## Todo Candidates`

Normal sections must use numbered lists. Todo Candidates must be numbered, and each short Todo must be wrapped in backticks.

## Minimum Template

```markdown
# YYYY-MM-DD Daily Brief

## Today

1. Project: one sentence explaining time, location, relevance, and any action needed now.

## Approaching Deadlines

1. Project: deadline or approaching schedule item, and whether action is needed.

## Needs Confirmation

1. Project: information or choice that needs user confirmation.

## Optional Events

1. Project: optional but valuable near-term event.

## Trash / Ignore

1. Project: general promotion, newsletter, or information that needs no action.

## Todo Candidates

1. `Project: action/keyword @YYYY-MM-DD`
2. `Project: undated action`
```

The daily brief carries background. Todo only reminds the user of actions.
